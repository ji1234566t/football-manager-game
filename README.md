# 足球经理模拟游戏 - 完整需求文档

## 📋 项目概述

开发一个足球经理（Football Manager）风格的模拟游戏，单HTML文件实现，支持移动端和桌面端，暗色主题UI。

### 核心目标
- 玩家扮演足球俱乐部主教练
- 从选择俱乐部开始，管理球队、转会、比赛、发布会
- 完整的赛季模拟系统（38轮联赛+杯赛）
- AI驱动的发布会发言分析和处罚系统
- 意见箱+后台管理系统

## ⚽ 比赛系统

### 比赛规则
- 联赛：每队38轮主客场
- 杯赛：小组赛+淘汰赛（自行设计）
- 欧冠：小组赛+淘汰赛（自行设计）

### 比赛引擎
- **实时时钟**：0-90分钟，正常速度推进
- **AI事件引擎**：传球、射门、进球、犯规、黄牌、角球，基于球员能力随机生成
- **动态比分**：进球时更新比分，显示进球者
- **实时统计**：射门、射正、控球率、角球、传球数、犯规
- **比赛日志**：滚动显示事件（类似FM解说栏）
- **动态阵型**：落后压上、领先收缩
- **球员评分**：每个球员实时评分（6.0-10.0）

### 比赛AI公式
```
射门概率 = 0.03 × (进攻能力 / 60) × 随机因子
进球概率 = 射正 × (进攻能力 / 150) + 0.1
犯规概率 = 0.05 × (防守能力 / 80)
控球率 = 0.5 + (比分差 × 0.02) + (能力差 × 0.01)
```

## 🎙️ 发布会与发言系统

### 三级违规判定

#### 🔴 严重违规（重罚）
- **辱骂/攻击裁判**：黑哨、瞎了眼、收钱了吧
- **人身攻击球员**：废了他、踢断腿、骗子、演戏
- **歧视言论**：种族/性别/地域歧视
- **批评管理层**：主席不懂球、管理层垃圾
- **煽动暴力**：弄死他们、报复
- **质疑联盟**：联盟针对、比赛被操控

**处罚**：禁赛3-10场 + 罚款£50,000-500,000 + 信任度-15%~50%

#### 🟡 中等违规（轻罚）
- 质疑裁判判罚（非人身攻击）
- 批评对手（非人身攻击）
- 抱怨赛程/场地
- 暗示裁判偏袒
- 阴阳怪气

**处罚**：警告/罚款£10,000-50,000 + 信任度-5%~10%

#### 🟢 轻微言论（无官方处罚）
- 批评自己球员
- 抱怨球队状态
- 语气不当
- 甩锅

**处罚**：更衣室支持率-10%~20%

### AI回应系统（风格匹配）
- 你攻击对方 → AI生成同等攻击性回应
- 你赞扬对方 → AI生成同等友善回应
- 攻击性指数匹配公式：`(你的攻击性 × 0.7) + (对方基础攻击性 × 0.3)`
- 口水仗等级：1口头交锋 → 2互相炮轰 → 3全面战争 → 4历史级恩怨

### 董事会开除机制

- 公开攻击俱乐部（信任度-50%）→ 解雇
- 连续3次被英足总处罚 → 解雇
- 歧视性言论 → 立即解雇

## ⚠️ 开发注意事项与踩过的坑

### 1. UI类名匹配问题（重要！）
- **坑**：弹窗CSS用了 `.modal-overlay`，但HTML写的是 `.modal`，导致弹窗完全不显示
- **解决**：确保HTML class和CSS选择器完全一致，弹窗统一用 `.modal-overlay`，通过添加 `.open` 类显示

### 2. DOM元素ID必须存在
- **坑**：`renderMyFeedback()` 函数找 `myFeedbackList`，但HTML里没这个元素，导致意见箱空白
- **解决**：所有JS引用的DOM ID都必须在HTML中提前定义

### 3. 函数初始化顺序
- **坑**：`renderMediaPage()` 在switchPage里调用，但函数还没定义
- **解决**：所有render函数必须在页面切换逻辑之前定义

### 4. 底部导航标签必须和页面对应
- **坑**：导航加了"媒体"标签，但没创建 `page-media` 页面，点击无反应
- **解决**：每加一个导航项，必须同时：
  1. 在bottomNav添加 `<div class="nav-item" data-page="xxx">`
  2. 创建 `<div id="page-xxx" class="page">`
  3. 在switchPage函数中添加 `if(page==='xxx') renderXxx()`

### 5. 中文编码问题
- 所有HTML文件必须UTF-8编码
- 球员名字、俱乐部名字全部中文
- 位置翻译：GK→门将、CB→中后卫、ST→前锋等

### 6. 移动端适配
- 按钮最小高度48px
- 卡片最大宽度600px居中
- 触控优化，避免误触
- 弹窗最大高度85vh，内容可滚动

### 7. 性能优化
- 比赛tick节流（250ms）
- 列表懒加载
- DOM操作最小化

### 8. 处罚力度要适中
- 不要一开始就重罚，玩家会觉得游戏太难
- 严重违规禁赛3-5场起步，不要一下就10场
- 罚款金额要和俱乐部预算匹配

### 9. 发布会响应速度
- 不要用setTimeout延迟
- 提交发言后立即显示分析结果
- 确保 `currentPressConference` 对象正确初始化

### 10. 不要省略任何球员数据
- 用户明确要求：五大联赛所有球员都要录入，不能只做知名球员
- 2845名球员，一个都不能少
